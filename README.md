# 🧪 Projetos de Teste Manual e Garantia de Qualidade (QA)

Este repositório contém meus primeiros casos de teste e relatório de bug desenvolvidos durante meus estudos na área de **Garantia de Qualidade de Software (QA)**.

---

## 📁 Estrutura do Repositório

- **`de teste/01-login.md`**: Caso de teste cobrindo a validação de login.
- **`de teste/02-cadastro.md`**: Caso de teste para o fluxo de cadastro de novo usuário.
- **`de teste/03-relatório-de-erros.md`**: Exemplo prático de um Bug Report detalhado contendo severidade, passos para reprodução e resultado esperado/obtido.

---

## 🛠️ Tecnologias e Conceitos Aplicados

- Testes Manuais (Functional Testing)
- Elaboração de Test Cases & Bug Reports
- Validação de Critérios de Aceite
- Documentação com Markdown e GitHub
